# Execution & Security

The final output of the NarrativeForge loop is a cryptographically signed **SSI Index Composition**.

## ValueChain (SoDEX L1)
The composition is published to the **ValueChain** using a secure blockchain client. By operating on ValueChain, NarrativeForge benefits from:

- **High Performance**: Sub-second finality for index updates.
- **On-Chain Orderbooks**: Direct liquidity integration for the thematic assets.
- **Agent-Friendly Infra**: Permissionless endpoint access for autonomous publishers.

## SSI Protocol
The SSI (Single Strategy Index) Protocol serves as the settlement layer. 
1. **Forge Request**: The agent sends the composition weights.
2. **Verification**: The protocol validates the publisher's reputation.
3. **Publication**: The index becomes live on-chain, accessible via the Forge Hub.

The "One-Person Business Empire" is realized by allowing individual developers to deploy these agents and earn through thematic index performance and reputation—all while maintaining full non-custodial security over the publishing keys.
